# AI-Based IaC Configuration Validation

An AI-assisted Infrastructure as Code configuration validation system using:

- Terraform
- Checkov
- AI explanation
- CVS
- Streamlit

## Workflow

Terraform Configuration
↓
CVS Version History
↓
Checkov Validation
↓
Security Findings
↓
AI Explanation
↓
Suggested Correction
↓
Re-validation
↓
Validated CVS Revision

## Main Features

- Terraform configuration editor
- Unsafe and safe demo configurations
- Real Checkov validation
- Security finding details
- AI explanations
- Suggested corrections
- Re-validation
- Before/after comparison
- CVS version history
- Audit logging
- Analytics
- Report generation
- Terraform plan validation

## Important

A PASS result means that no failed Checkov checks were reported under the configured policies. It does not guarantee complete security.
